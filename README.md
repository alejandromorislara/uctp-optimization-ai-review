# Metaheuristics for University Course Timetabling

This repository contains the initial research proposal for Practice 1 of *Methodology and Research Techniques* in the Master's Degree in Machine Learning and Big Data.

The proposed study has two parts. First, it will review the recent literature on metaheuristic methods for the University Course Timetabling Problem. It will then implement Genetic Algorithm and Simulated Annealing under a common experimental setup and compare them on the ITC-2007 curriculum-based benchmark. A constructive greedy solver will provide a simple baseline.

The proposal defines the literature-search protocol, research questions, benchmark, evaluation measures, statistical comparison, and main threats to validity. The scope is intentionally limited to methods that can be implemented, inspected, and reproduced within the course schedule.
